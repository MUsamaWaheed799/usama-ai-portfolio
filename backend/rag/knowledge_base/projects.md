# Projects

## 1. AquaX AI — Smart Irrigation Advisory System
Problem: Many Pakistani farmers lack easy access to data-driven irrigation guidance, leading to water waste and inconsistent crop yields.

Solution: AquaX AI is an AI-powered irrigation assistant that combines a Gemma LLM's reasoning with live weather data to generate practical, localized irrigation recommendations. It supports voice interaction so farmers with limited literacy can use it.

Tech Stack: Gemma AI model, FastAPI backend, Open-Meteo API for weather data, SQLite database, Google Cloud Speech-to-Text, Google Cloud Text-to-Speech, HTML/CSS/JavaScript frontend, deployed on Railway.

Features:
- Natural-language irrigation advice generated from live weather conditions
- Voice input and voice output for accessibility
- Lightweight deployment suitable for low-resource environments

Context: Built for the Build with Gemma Hackathon. Usama also redesigned and rebuilt the pitch deck (slides 2-6) programmatically using python-pptx, preserving the original visual theme while improving clarity and structure.

Links: GitHub — github.com/MUsamaWaheed799 (see AquaX AI repository)

## 2. Usama AI Portfolio Agent (this project)
Problem: A static resume or portfolio site doesn't let recruiters ask specific questions about a candidate's experience in real time.

Solution: A personal brand website with an integrated RAG-based AI agent ("Usama AI Assistant") that answers recruiter and visitor questions using only Usama's actual resume, project, and skills data — demonstrating applied AI Fluency, prompt engineering, and full-stack AI agent implementation.

Tech Stack: Next.js 16, TypeScript, Tailwind CSS, shadcn/ui, Python FastAPI, RAG pipeline with embeddings and a vector store, deployed on Vercel (frontend) and Railway/Render (backend).

## 6. Digital Scoreboard Circuit
Problem: Digital Logic Design coursework requiring a hardware-level scoreboard system.

Solution: Designed and simulated a digital scoreboard circuit using an SR Latch, BCD Counter, and 7-Segment Display, implemented and verified across multiple simulation platforms.
